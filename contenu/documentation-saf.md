# Comment écrire ce livret

Ce fichier est lu tel quel par `documentation-saf.php` — rien à toucher côté
site, seul ce texte compte. Le format est volontairement pauvre :

Un chapitre commence à chaque ligne qui débute par `# ` suivi de son titre.
Tout ce qui suit, jusqu'au prochain `# `, est le corps du chapitre. Une
ligne vide sépare deux paragraphes ; à l'intérieur d'un paragraphe, les
sauts de ligne ne sont qu'une largeur de colonne pour l'écrire — ils
disparaissent à l'affichage. **Deux astérisques** mettent un mot ou une
phrase en gras, comme ici.

Rien d'autre n'est lu : pas de listes, pas de liens, pas de sous-titres,
pas d'images. Chaque chapitre est une page du livret qu'on tourne sur le
bureau — voir `documentation-atelier.md` pour un livret complet, déjà en
place, comme second exemple.

Remplacez ce chapitre et le suivant par les vôtres ; ajoutez-en autant que
nécessaire, dans l'ordre où ils doivent se lire.
