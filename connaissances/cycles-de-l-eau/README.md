# Les cycles de l'eau — corpus de méthode

**Lecture seule**, comme le reste de `connaissances/`.

## Pourquoi ce dossier existe

Le ch. 7 de *Bienvenue en Syntropie !* — « L'eau, ça se plante » — pose le **cycle secret de l'eau** et ses quatre mécanismes : condensation entre strates, tourbillon descendant, noyaux de condensation, stockage dans le sol. Il les affirme **sans les sourcer ni les chiffrer**, et le dépôt signale d'ailleurs l'un de ses chiffres comme douteux.

Ce corpus donne les mécanismes, les sources et les ordres de grandeur.
